# PAXI - Producer Ally's Export Assistant

## Overview
PAXI is a web-based application designed specifically for South African perishable cargo exporters. It provides quick access to commodity information, transit times, and essential resources for freight forwarding operations.

## Features
- **Commodity Database**: Searchable database of HS codes, temperature requirements, and PPECB protocols
- **Transit Calculator**: Port-to-port transit time estimates with carrier information
- **Resource Hub**: Quick access to PPECB, NDA, and carrier websites
- **Mobile Responsive**: Works on all devices
